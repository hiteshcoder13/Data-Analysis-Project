TROUBLESHOOTING:
═══════════════════════════════════════════════════════════════════════════

Problem: "module not found" or "No module named..."
Solution: Make sure virtual environment is activated
  Run: source venv/bin/activate

Problem: "File not found"
Solution: Check that file exists and path is correct
  Try: ls -la your_file.csv

Problem: "Unsupported file format"
Solution: Use one of these formats: CSV, JSON, XLSX, XLS, TSV, TXT

Problem: Nothing happens when I run the command
Solution: Check for error messages. Make sure you're in the right directory:
  cd /home/Unthinkable/Documents/Data-analysis-Project

Problem: Report file is very small or blank
Solution: Check that your data file is not empty
  Try: head your_data.csv

UNDERSTANDING KEY CONCEPTS:
═══════════════════════════════════════════════════════════════════════════

MISSING DATA
  Why it matters: Can bias your analysis
  What to do: Check the "Missing Data Analysis" section
  Action: Decide whether to remove, impute, or ignore

OUTLIERS
  Why it matters: Can skew statistical analysis
  What to do: Check the "Outlier Detection" section
  Action: Investigate and decide on treatment

SKEWNESS
  Why it matters: Affects model performance
  What to do: Check "Distribution Analysis"
  Action: Consider log or power transformation if highly skewed

CLASS IMBALANCE
  Why it matters: Can mislead classification models
  What to do: Check "Class Balance Analysis"
  Action: Use techniques like SMOTE if ratio > 3

CORRELATION
  Why it matters: Too many correlated features slow down models
  What to do: Check "Correlation Analysis"
  Action: Remove highly correlated features (r > 0.9)
