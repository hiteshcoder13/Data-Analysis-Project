ANALYSIS OUTPUT INCLUDES:
═══════════════════════════════════════════════════════════════════════════

DATA PROFILING:
  • Total rows, columns, data types
  • Missing value analysis with visualizations
  • Duplicate detection
  • Memory usage statistics

STATISTICAL ANALYSIS:
  • Mean, median, standard deviation
  • Quartiles (Q1, Q2, Q3) and IQR
  • Min/Max values and range
  • Variance and coefficient of variation

DISTRIBUTION ANALYSIS:
  • Normality tests (Shapiro-Wilk test)
  • Skewness analysis (symmetric, left-skewed, right-skewed)
  • Kurtosis analysis (tail behavior)
  • Distribution type interpretation

CATEGORICAL ANALYSIS:
  • Unique values per column
  • Value frequency counts
  • Top values and distributions
  • Missing values in categorical columns

OUTLIER DETECTION:
  • IQR-based outlier identification
  • Outlier bounds (lower and upper)
  • Outlier count and percentage
  • Outlier visualization

CLASS BALANCE ANALYSIS:
  • Unique class counts
  • Class distribution percentages
  • Imbalance ratio calculation
  • Balance assessment (balanced/imbalanced)

CORRELATION ANALYSIS:
  • Pearson correlation matrix
  • Strong correlations identification (|r| > 0.7)
  • Correlation heatmaps

VISUALIZATIONS:
  • Distribution histograms
  • Box plots for outlier visualization
  • Categorical bar charts
  • Correlation heatmaps
  • Missing data pattern visualization
  • All charts embedded in DOCX report

TROUBLESHOOTING:
═══════════════════════════════════════════════════════════════════════════

Issue: "module not found" error
→ Activate virtual environment: source venv/bin/activate

Issue: "file not found" error
→ Check file path and ensure file exists

Issue: "Unsupported format" error
→ Use one of: CSV, JSON, XLSX, XLS, TSV, TXT

Issue: Analysis is slow
→ Normal for large files. <1MB: 5-10s, 1-50MB: 15-30s, >50MB: 1-2min

Issue: Report is blank or small
→ Check that your data file isn't empty and has proper formatting
